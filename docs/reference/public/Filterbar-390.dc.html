Pille «weitere Filter (N)»

Bei 390 heisst die Pille «Filter (N)». N zählt Filterarten, nicht Werte. Die Beschriftung öffnet das Overlay, das × entfernt alle weiteren Filter. Einzelne Werte entfernt man im Overlay.

Hover und Fokus

Hover: heller Grund. Fokus: 2 px Kontur ohne Abstand, damit die scrollende Pille sie nicht abschneidet.

Overlay «Anlass», ein Anlass gewählt

Ein Chip pro Anlass, den mindestens eine Location trägt, in der Reihenfolge des Vokabulars. Mehrere gewählt erweitern das Resultat (oder). Gleiche Karte und Chips wie «weitere Filter»; das weisse Band unten zählt live.
