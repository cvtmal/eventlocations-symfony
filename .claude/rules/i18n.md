# Internationalisation

Languages, catalogues, routes: read before adding visible text, a route or a translated field. German only (E3): `default_locale: de`, `enabled_locales: [de]`, translator `fallbacks: [de]`; no other language is planned, but the machinery stays. Hotspots (`docs/rpi-cycles.md` "Running cycles in parallel"): `config/packages/translation.yaml` and `src/Shared/Translation/*` belong to the tech lead, other cycles change nothing there.

## Catalogues

- The locale comes from the URL only (`set_locale_from_accept_language: false`: cacheable pages); `set_content_language_from_locale` sends `Content-Language: de`. `EnabledLocale` (`all()`, `default()`, `isEnabled()`, `clamp()`) is the only source of served locales in PHP; never read `%kernel.enabled_locales%`.
- Every user-facing string goes through a catalogue (`|trans`, the translator), never written into a template or PHP class. One ICU domain per module, `translations/<module>+intl-icu.de.yaml` (`messages`: layout strings only, hotspot); keys are `<context>.<description>`.
- Tone is "du" (E4), Swiss "ss" never the eszett, buttons short imperatives or nouns; `admin`, `cms`, `crm` are informal (`PublicCopyAddressTest`, `validators` overrides: `CLAUDE.md` "German copy").
- Pass numbers to messages pre-formatted with `swiss_number`, never through ICU `{n, number}` (the translator locale is `de`, so ICU would group with `.`); `plural`/`select` are fine.
- Fixed vocabularies (cantons, taxonomy terms, tiers, badges) are PHP enums or code-keyed rows with labels from catalogues. An enum implements `TranslatableInterface`, key `<context>.<case value>` in the module's domain. Keys built at runtime are invisible to `debug:translation` and `TranslationCompletenessTest`, so each such enum gets a test that every case's key exists in `de`.
- Format with `swiss_number` (`1'234'567.5`), `swiss_date` (`05.10.2026`) and `swiss_range(min, max)` (`50 - 450`, ASCII hyphen; one number if equal) from `Shared\Twig\SwissFormatExtension`, never `|date` or `number_format`. Storage and PHP stay UTC; only display is Europe/Zurich.

## Routes and hreflang

- Every public route is declared localized, `#[Route(path: ['de' => '/hochzeitslocations'], name: 'listing')]`; Twig and PHP call `path('listing')` with no locale. Query parameters are language-neutral codes (`?canton=zh`); landing page slugs are localized.
- Exempt are technical routes only: a name starting `_`, a path starting `/_`, or `options: [LocalizedRoutes::UNLOCALIZED => true]`. `PublicRoutesAreLocalizedTest` fails on any other route outside the localized form.
- `hreflang_alternates(query = {})` (`HreflangExtension`, `HreflangAlternates`; partial `shared/_hreflang.html.twig`) gives `<locale>-CH` plus `x-default`; pass `query` when a parameter selects another page. Unsafe requests, technical routes and error pages get none.

## Content translations

- `<entity>_translations`: indexed FK `<entity>_id`, `locale VARCHAR(2)`, `uk_<table>_<entity>_id_locale UNIQUE (<entity>_id, locale)`, `chk_<table>_locale CHECK (locale ~ '^[a-z]{2}$')`. The venue name is a proper noun and stays on `venues`.
- Validate `locale` with `EnabledLocale::isEnabled()`; every owner has a `de` row. The entity is a plain per-module class (`Venues\Entity\VenueTranslation`), unidirectional `ManyToOne`, no shared trait or mapped superclass.
- Read models join with `TranslationJoin::localized()` plus `parameters($locale)` (`:i18n_locale`, `:i18n_fallback_locale`): a `LEFT JOIN LATERAL` for the requested locale, else the `de` row, per row; an owner with no row keeps `NULL` fields; identifiers are validated because interpolated.

## Checks

- `make lint-translations` fails on a broken ICU message; `tests/Integration/Shared/Translation/` checks completeness, parity and raw template text (`TemplatesHaveNoRawTextTest`: `BASELINE` empty, only shrinks). The scanner misses text passed as a variable to includes, macros or components, and strings in PHP: review those.

## Enabling a new language

Not additive (E3, S4 in `docs/rpi-cycles.md`): catalogues and route paths alone do not add a language; an `i18n-core` cycle comes first, and none is planned.
