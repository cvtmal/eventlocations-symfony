### Admin

Back-office foundation at `/admin` (S12): staff login, shell, extension points, audit log, Vue islands.

**Built in #22 (`admin-foundation`).** Migration `Version20261030152714`; mapping `orm.mappings.Admin`; Composer `symfony/security-bundle`, `scheb/2fa-bundle`, `scheb/2fa-totp`, `bacon/bacon-qr-code`; `config/packages/security.yaml` is #22's hotspot (others use `#[IsGranted]`).

- **Dev admin:** `make seed` creates `admin@hochzeitslocation.test`, password `admin-dev-password`, TOTP secret `JBSWY3DPEHPK3PXPJBSWY3DPEHPK3PXP` (`App\Story\AdminStory`; public on purpose, dev data only). `make sf c="app:admin:reset-2fa admin@hochzeitslocation.test"` lets you enrol your own app.
- **Tables:** `admin_users` (e-mail stored lower-case, `role` admin|editor, `totp_secret_encrypted` NULL until enrolled, `is_active`; deactivated, never deleted) and `admin_audit_log` (append-only, so no `updated_at`; `actor_type` admin_user|console|system, `actor_id` only for admin_user, `changes` JSONB). `AdminUser(string $id, …)` takes its id from the caller (`EntityId::generate()` before dispatch), so `auditSubject()` knows it.
- **Security:** one firewall on `^/admin(/|$)`, nothing elsewhere, so public pages stay session-free (S10); the session cookie is `SameSite=Strict`, `HttpOnly`, path `/admin`. Form login (5 tries per 15 minutes), mandatory TOTP (`TotpSecretCipher`, sodium secretbox, key `ADMIN_TOTP_KEY`; #20 generates production's), first-login enrolment at `/admin/2fa/einrichten` (`RequireTotpEnrolmentListener`), 5 wrong codes per user per 15 minutes (`TotpThrottleListener` + `TotpFailureHandler`, limiter `admin_totp`), 2-hour idle timeout (`IdleTimeoutListener`, session key `admin.last_seen`), `Cache-Control: no-store, private` and `X-Robots-Tag: noindex, nofollow` on everything under `/admin` (`AdminResponseHeadersListener`). A deactivated account is refused after the password check (`RefuseInactiveAdminListener`, a `CheckPassportEvent` listener: `checkPreAuth` would disclose it, and scheb stops the event `checkPostAuth` runs on for a user with TOTP). **Anything that decides by "is this the back office?" asks `Security\AdminArea` (`contains()`, `isJson()`), never the raw path:** the router and the firewall decode the path, so `/%61dmin/benutzer` is `/admin/benutzer` to them. `Security\AdminIdentity` is the security user, built per request by `AdminUserProvider`; the session holds fingerprints only, so a password, role or 2FA change ends that user's sessions. `ROLE_ADMIN` includes `ROLE_EDITOR`.
- **Routes:** `admin_dashboard` `/admin`, `admin_login`, `admin_2fa_login`, `admin_2fa_check`, `admin_totp_enrol`, `_logout_admin` (POST only, declared in `config/routes/security.yaml` because Symfony's generated route allows any method), `admin_users*` `/admin/benutzer…`, `admin_audit_log` `/admin/audit-log` (filters `actor`, `subject_type`, `subject_id`, `from`, `to`), `admin_styleguide` `/admin/_styleguide` (dev, test). New routes: `options: [LocalizedRoutes::UNLOCALIZED => true]`, a name starting `admin_`, `#[IsGranted]`. `AdminRoutesAreProtectedTest` walks the router (trait `ChecksAdminRoutes`) for every route and method as anonymous, in the code step, unenrolled, editor and admin, canonical and percent-encoded. It fills every route parameter with a UUID, so a new route is covered without touching the test only if its parameters accept one: with a stricter requirement such as `\d+` the walker gets a 404 and fails loudly until it is taught that parameter's value (`ChecksAdminRoutes::adminEndpoints()`). `ExtensionPointsTest` runs the same walk on the fake module's routes.
- **Console:** `app:admin:create-user <email> --role=admin|editor [--name=…]`, `app:admin:reset-2fa <email>`, `app:admin:reset-password <email>`.
- **Audit:** a command implements `Shared\Messenger\AuditableCommand` (`auditSubject(): AuditSubject`, `auditSummary()`, never a password or secret) and `Admin\Messenger\AuditLogMiddleware` writes the row inside the transaction. `Admin\ReadModel\AuditLogQuery::forSubject($type, $id, $limit)` serves "Zuletzt bearbeitet von"; `forSubjects($type, $ids, $commands, $limit, $before, $changedMustInclude)` serves the CRM timeline (#27): several subjects, a command allow-list, a keyset, and a cut on `changes.changed` in SQL.
- **Extension points** (`Admin\Extension`): implement `NavigationItem`, `DashboardWidget`, `RecordTab`, `RecordPanel`, `SearchProvider` or `TimelineActivityType` (#27) in your module's `Extension` layer; autoconfiguration registers it. Twig: `admin_navigation()`, `admin_dashboard_widgets()`, `admin_record_tabs(type, id)`, `admin_record_panels(type, id)`; all filter by `requiredRole()` and sort by `priority()` descending. `TimelineActivityType` has no Twig function: `TimelineActivityTypeRegistry` (`visible()`, `composable()`, `composableCodes()`, `isComposable()`) feeds `Crm\TimelineProps`. The fake module in `tests/Fixtures/Admin/` shows each one.
- **Shell:** `templates/admin/base.html.twig` blocks `title`, `body_class`, `breadcrumbs` (`<li class="breadcrumbs__item">`), `page_actions`, `page_header`, `main`, `aside`, `scripts`; `layout/_sidebar`, `_topbar`, `_flash`; the search trigger is the slot `admin/layout/_search_trigger.html.twig` (#23). Flashes are toasts: types `success`, `error`, the message a key of the `admin` catalogue. Form rows come from the form theme `admin/form/theme.html.twig` (#23), which links each error to its input. Styles: `assets/styles/admin.scss` (append one `@use` per partial) with `--a-*` tokens, never loaded with `app.css`. Icons: `{{ admin_icon('name', label) }}` from `assets/icons/admin-sprite.svg`. Strings: the `admin` domain.
- **Vue islands:** one line in `admin-ui/src/islands.js`, the file `admin-ui/src/islands/<Pascal>Island.vue` (`<script setup>`, no `<style>`, no bare strings). In Twig: `{{ admin_island('hello', {greeting: '…'|trans({}, 'admin')}) }}`. `admin_island_assets(nonce = null)` closes `base.html.twig` and loads only what the page used. Every `/admin` page reads the Vite manifest (the sidebar's deferred palette), so a missing `make admin-build` is a 500 on every sidebar page; `make init` builds it.
- **JSON endpoints:** `/admin/api/<module>/…`, route names `admin_api_<module>_…`, class-level `#[IsGranted]` and `#[IsCsrfTokenValid('admin_api', tokenKey: 'X-CSRF-Token', tokenSource: IsCsrfTokenValid::SOURCE_HEADER, methods: [...])]` (the token is in `<meta name="csrf-token">`); validation errors answer 422 with `ValidationErrors::fromViolations()|fromForm()`, `{"errors": {"field": ["message"]}}`; 401 and 403 are JSON too.
- **Budgets (ADM-8):** `AdminAssetBudgetTest`: shared JS ≤ 60 KB gzip, each island ≤ 30 KB, admin CSS ≤ 30 KB.

**Built in #23 (`admin-ui-kit`).** No migration; Composer `league/commonmark` (`^2.10.2`, in Shared); no npm additions. Every component with every variant: `/admin/_styleguide` (`templates/admin/styleguide/_components.html.twig`, one `<section data-component>` each).

- **Twig components** (`templates/admin/components/`, each opens with a docblock of its params; strings arrive translated). Atoms by `include … with_context = false`: `_button` (`label`, `variant` primary|secondary|ghost|danger, `size` sm|xs|lg, `icon`, `icon_only`, `href`, `type`, `attributes`), `_pill` (`label`, `tone` green|grey|pink|blue|amber|red|dark, `dot`), `_tier_badge` (`tier`, `label`; a Twig map of the `Tier` values, so Admin stays free of Venues), `_avatar`, `_empty`, `_skeleton`, `_kpi`, `_progress` (native `<progress>`), `_property`, `_filter_chip`, `_chip_check`, `_seg`, `_timeline_item`, `_kanban_card`, `_dropzone` (a real file input over the zone), `_required_hint`, `_tabs` (links, `aria-current`), `_record_tabs` (`tabs` from `admin_record_tabs()`, `current_route`), `_pagination` (`page`, `last_page`, `total`, `per_page`; status `ui.pagination.status`), `_locale_tabs` (`locales`, `panels`: a tablist from two locales, a plain label for one, all panels without JS). Shells by `embed … only`: `_card` (blocks `actions`, `body`, `foot`), `_table` (`columns` list<{label, sort_key}>, `sort`, `dir`; blocks `rows`, `empty`; a sort header is a link `sort=<key>&dir=asc|desc` with `aria-sort`), `_table_row` (`cells`, `actions`), `_filter_bar` (visible "Filtern" button; block `filters`), `_modal`/`_drawer` (`<dialog data-dialog>`, the contract of `components/_dialog`; blocks `body`, `footer`; a destructive confirm gives Cancel `autofocus`), `_dropdown` (`popover`; block `items`), `_kanban_column`, `_record_header` (blocks `meta`, `actions`, `tabs`), `_sortable` (POST move-up/down forms for server pages, `aria-disabled` at the ends). Styles: one `assets/styles/admin/_<component>.scss` each. Input borders use `--a-field-strong` (≥ 3:1, `AdminInputContrastTest`).
- **Form theme:** `{% form_theme form 'admin/form/theme.html.twig' %}` per template; never `twig.form_themes`, so the public inquiry form cannot inherit it (`FormThemeTest` pins it). `aria-describedby` joins help, counter, error, then a caller value; `required` shows `*` (add `_required_hint` to the form), `required: false` shows nothing; expanded choices are a `fieldset`; `attr: {'data-counter-max': n}` adds a counter (not `maxlength`; `char-counter.js` counts as the server does); money fields need `html5: true` (locale-independent `type=number`), shown with `.field__addon` CHF. #22's `form/_field.html.twig` is gone. `Admin\Form\ComboboxType` (options `url`, `static_options`, `display_value`, `free_text`): select mode submits a hidden value and shows `display_value`; free-text mode (`free_text: true`, value = label, #24's "PLZ / Ort") submits the visible input as typed; both together throw. The plain input is the island's `fallback`, so it submits before the mount and without JS. A `url` answers `{"options": [{"value", "label", "detail"}]}`. `Admin\Form\MarkdownType` (Schreiben/Vorschau tabs, preview from `admin_api_markdown_preview`).
- **Twig functions:** `admin_island(name, props, fallback = '')` (the fallback sits unescaped inside the mount point), `admin_island_deferred(name, props)` (`data-island-defer`, loads nothing, `anyUsed()` stays false), `admin_query_path(changes)` (current route and query with `changes` merged; null removes a key; `page` is dropped unless named), `admin_page_links(page, last)`.
- **Scripts:** `templates/admin/components/_scripts.html.twig` (included by `base.html.twig`) loads `js/dialog.js` and `js/admin/{palette-trigger,tabs,dropdown,char-counter,markdown-preview}.js` on every back-office page; a new file goes there, and `AdminAssetBudgetTest` globs `assets/js/admin/*.js`. They delegate at document level, so they also work on island markup. `palette-trigger.js` is the one `import()` (see `.claude/rules/frontend.md`): it imports the entry on first click or ⌘K/Ctrl+K and dispatches `admin:mount-islands`, which `main.js` listens for (an app build keeps no entry exports).
- **Vue kit** (`admin-ui/src/`, imported only by islands): `components/Ui{Icon,Button,Pill,Avatar,Empty,Skeleton,TableRow,Modal,Drawer,KanbanColumn,KanbanCard,TimelineItem,Dropzone,SortableList,Combobox}.vue` (same classes and markup as the Twig twins, labels as props; Twig/Vue parity for button, pill, table row and modal is pinned by `admin-ui/tests/fixtures/markup/*.html`, checked by `ComponentMarkupFixturesTest` and `markup-parity.test.js`), `composables/useToast.js` (`_flash` markup), `useListbox.js`, `icons.js` (`<meta name="admin-sprite">`). Islands: `command-palette`, `combobox`, `styleguide-sortable` (styleguide demo). ESLint forbids static inline styles; `tests/setup.js` stubs `<dialog>` for jsdom.
- **`adminFetch(url, {method, body, signal})`** (`admin-ui/src/api.js`; CSRF header, `redirect: 'manual'`): a redirect, 401 or 2xx non-JSON throws `SessionGone`; 204 gives `null`; 2xx JSON the body; 422 JSON `ValidationFailed` (`.errors`); any other status `RequestFailed` (`.status`), so a 413, 500 or 504 never reports a lost session. `markdown-preview.js` repeats these rules.
- **Global search:** `SearchProvider` now also has `label(): TranslatableInterface`, `priority()`, `requiredRole()`. `SearchProviderRegistry::search($q)` asks each visible provider for ≤ 5 results and drops empty groups (`ValueObject\SearchGroup`). `admin_api_search` `GET /admin/api/search?q=` (editor; no CSRF on a read) answers `{"groups": [{"label", "results": [{"type", "label", "detail", "url"}]}]}`; `q` is trimmed and cut to 100 characters, and fewer than 2, invalid UTF-8, a NUL or an array give no groups. The sidebar slot `layout/_search_trigger.html.twig` holds the button and the deferred palette. `admin_api_markdown_preview` `POST /admin/api/markdown-preview` (`{"text"}` ≤ 20000 → `{"html"}`). Both paths depart from `/admin/api/<module>/…`: they belong to no module. The route walker (`ChecksAdminRoutes`) now accepts GET JSON routes.
- **`Shared\Markdown\MarkdownRenderer::render()`:** CommonMark core only, raw HTML escaped, unsafe links dropped, nesting and delimiter limits; the options are security settings.
- **Strings:** the kit's keys are an appended `ui:` block in the `admin` catalogue (`ui.<component>.<name>`, styleguide samples `ui.styleguide.*`).
- **Tests:** `PublicPagesLoadNoAdminAssetsTest` (no admin marker on public pages, the markers are real on the styleguide, no public template uses `admin_*`, no `--a-*` in `app.css`); `AdminAssetBudgetTest` counts a chunk shared between islands against each and every vanilla script in the shared budget.

**Built in #24.** `Admin\Form\AdminTextConstraintExtension` adds `CleanText` to every `TextType` descendant under the back office (resolved against the main request, so the public inquiry form and the console are untouched); a textarea already submits LF only (Symfony 7.4's `TextareaType`). `ChecksAdminRoutes` fills a parameter with `Cms\ValueObject\VenueNumber::REQUIREMENT` with `1` instead of a UUID, and `assertNotTurnedAway()` also asserts `< 500`. `_record_header` has an optional `media` block and `_locale_tabs` an `active` locale (default the first). `js/dialog.js` returns focus to the owning popover's trigger (else the opener) when a dialog closes with focus on `<body>`, because an opener inside a closed popover cannot take it back.

**Built in #35.** `--a-accent-bright` (#FF0096, `assets/styles/admin/_tokens.scss`) is for icons on dark grounds only (the sidebar's active item, the error toast): `--a-accent` must carry white text and so is too dark there, and one value cannot pass both roles (3.63:1 on #2f2f2f, 4.67:1 on #1b1b1b).

**Built in #27.** No Admin migration or route.

- **`TimelineActivityType`:** `code()`, `label()`, `priority()`, `requiredRole()`, `composable()`, tag `admin.timeline_activity_type`. The method for staff writes is `composable()`: false for kinds only the system writes. `isComposable()` ignores the role, because a handler has no session; the role is the controller's, through `composableCodes()`. The fake module has `FakeTimelineActivityType`. How a kind is added: `.claude/rules/module-crm.md`.
- **Kit:** `UiTimelineItem.vue` and `_timeline_item` take a default slot after the body, and `.timeline-item__icon--amber`, `--grey` are new tones. `UiCombobox` has an `autofocus` prop, passed by the form theme from `attr.autofocus`, and prevents the default of Esc while its list is open, so an editing row or a dialog stays open. `useListbox.js` keeps the active option in view. `.modal__body .combobox__list` is `position: static`, so a list in a modal takes room in the body instead of being clipped.
- **Dashboard:** `.widget` and `.widget__head-link` (`admin/_dashboard.scss`) put a link in a widget's head, which Admin's dashboard template draws. #29's Neue Anfragen can use them.
- **Sidebar badge:** `.sidebar__badge` has one tone, pink, and `NavigationItem::badge(): ?int` has none. The design draws Aufgaben dark grey and Anfragen pink, so a second tone changes this extension point.
- **Icons:** `calendar`, `phone`, `sticky-note` in `admin-sprite.svg`.
- **Double submit:** plain forms double-POST on a double click across the back office; only islands guard against it (`saving`).
